# scripts/ —— 交付自检

> 用途:本目录存放端到端冒烟自检脚本,是本仓主力门禁之一。

当前只有一个脚本:`smoke.mjs`,零依赖(Node 22+ 原生 fetch),对运行中的实例按用户旅程
走完 14 步并逐项断言,末步清理自建数据。测试分层与改动验证表见 [docs/TESTING.md](../docs/TESTING.md)。

## 文件清单

| 文件 | 干什么 | 备注 |
|---|---|---|
| `smoke.mjs` | 14 步端到端自检(上传→文献→审稿→导出→对照→核查→洞察→清理) | `npm run smoke` 入口;`SMOKE_BASE_URL` 可验线上 |

## 和谁打交道

- **上游**:运行中的实例(`localhost:3000` 或线上域名)、`.env.local` 的 key(真实模式)。
- **下游**:输出 14 行步骤结果与汇总行;核查报告引用其结论。
- **改这里之后要跑**:先 `LLM_API_KEY= npm run smoke`(演示模式)确认脚本自身可跑,再按需真实验证。

## 别动

- 步骤顺序即依赖顺序:修改稿对照依赖审稿线程存在,清理必须最后;调序会连环失败。
- 清理步骤删除的是**本脚本自建**的稿件(按创建时返回的 id),不会删用户数据;但勿把
  `projectId` 改成固定值,否则会误删同名项目。
